# Source manifest notes (Oct 28, 2026)

- Excluded on purpose: ATP 3-50.3 (2012, Distribution D: DoD and contractors only) and TC 3-25.26 (2013, distribution restricted to US government agencies). Their restricted copies were deleted. Public-release predecessors are used instead: FM 21-76-1 (1999) and FM 3-25.26 (2001).
- FM 21-76: the official FM 21-76 / MCRP 3-02F text replaces a third-party reprint that carried added material.
- irp.fas.org serves a bot challenge to scripts, so archive.org copies are used. Each PDF's front matter was checked for its distribution statement.
- cdc-water: cdc.gov refuses scripted downloads. Read it in a browser when drafting the Water track.
- Gutenberg .txt files include the Project Gutenberg license header and footer; strip them before extraction. The books themselves are public domain.
